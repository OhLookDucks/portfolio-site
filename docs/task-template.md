# Task template

Copy this, fill it in, and send it to the agent. One task per message.

**Task:** (one sentence, e.g. "Add a Projects section to the home page")

**Objective:** What should be different when it's done?

**Acceptance criteria (what "done" looks like):**
- (e.g. The section appears under About, in the same warm style)
- (e.g. It looks fine on phone and desktop)

**Target files:** (which files may change; if unsure write "you tell me first")

**Verification:** (how we check it, e.g. "open the page and click every link", "no typos", "no phone number or town visible")

---

## Example
**Task:** Add my job-application tracker as a project card.
**Objective:** Visitors can see what I built and what it does.
**Acceptance criteria:** One card with title, 2-line description and a screenshot; matches existing card style; mobile layout still fine.
**Target files:** the page that lists projects, plus one new image.
**Verification:** Preview the page, check the card on a narrow window, confirm nothing else moved.
