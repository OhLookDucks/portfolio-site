# 0003: npm as the package manager
Decision: use npm only. Never mix in pnpm or yarn, and never delete `package-lock.json`.
Why: it is already the tool the owner has (Node 24 ships with npm), it is the simplest choice for a beginner, and the shadcn scaffold produced a `package-lock.json` anyway.
Details:
- `package-lock.json` is committed and must stay in sync with `package.json`.
- Netlify builds use npm by default when it detects a `package-lock.json`.
- The scaffold metadata `.cta.json` was corrected to record npm (it initially said pnpm).
